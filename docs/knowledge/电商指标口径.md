# 电商运营指标知识库

## GMV 与净销售额

成交 GMV 是统计周期内所有已下单订单金额之和。实际销售额为已付款金额扣除优惠券、满减和运费，并剔除全额退款订单。净销售额等于实际销售额减去退款成功入账金额；部分退款按实际退款金额扣除。

## 转化与流量

店铺 UV 按设备或账号去重，PV 不去重。下单转化率等于下单 UV 除以店铺 UV，付款转化率等于付款 UV 除以下单 UV，整体转化等于付款 UV 除以店铺 UV。渠道必须按自然搜索、推荐、付费投放、直播、短视频和活动流量分别统计，不能跨渠道合并。

## 投放与异常

直接 ROI 等于投放直接成交 GMV 除以投放消耗；CTR 等于点击量除以曝光量。指标相对基线的变化在 5% 到 15% 为轻微波动，15% 到 30% 为显著波动，超过 30% 为严重异动。基线统一采用日环比、周同比和月环比。
